# 4. Trang Liên hệ & Hỗ trợ Doanh nghiệp (Contact)

## 4.1. Route

Route hiển thị giao diện:

```text
GET /contact
```

Route tiếp nhận và xử lý biểu mẫu liên hệ:

```text
POST /contact
```

Trang public, không bắt buộc đăng nhập (hỗ trợ cả khách vãng lai lẫn nhân sự doanh nghiệp gửi yêu cầu).

---

## 4.2. Mục tiêu

Trang Liên hệ DrinkFlow đóng vai trò là cổng tiếp nhận chính thức cho:

- **Hỗ trợ nghiệp vụ & tài khoản**: Giải quyết thắc mắc đối soát, gỡ nợ đọng VietQR Napas, phục hồi trạng thái khóa phiên.
- **Triển khai văn phòng mới**: Tiếp nhận nhu cầu áp dụng DrinkFlow cho chi nhánh hoặc doanh nghiệp đối tác.
- **Hợp tác nhà cung cấp (Merchant)**: Các quán trà sữa, cà phê, chuỗi đồ uống gửi thông tin menu để liên kết bán hàng nội bộ.
- **Phản hồi & Đóng góp tính năng**: Lắng nghe trải nghiệm thực tế từ Host và Room Member.
- **Bảo vệ chống Spam**: Tích hợp mã Captcha (`mews/captcha`) xác thực người thật trước khi ghi nhận vào hệ thống.

## 4.4. Cấu trúc Biểu mẫu (Contact Form Specifications)

| Trường dữ liệu | Tên tham số | Kiểu dữ liệu | Bắt buộc | Ràng buộc validation | Ghi chú |
| :--- | :--- | :--- | :---: | :--- | :--- |
| **Họ và tên** | `full_name` | String | Có | `required|string|max:100` | Tên người gửi |
| **Email doanh nghiệp** | `work_email` | String | Có | `required|email|max:150` | Email nhận phản hồi |
| **Số điện thoại** | `phone` | String | Có | `required|string|max:20` | Hotline liên hệ nhanh |
| **Bộ phận / Công ty** | `company` | String | Có | `required|string|max:150` | Phòng ban hoặc tên pháp nhân |
| **Chủ đề yêu cầu** | `topic` | String | Có | `required|in:vietqr,deploy,feedback,merchant,other` | Danh mục hỗ trợ |
| **Nội dung tin nhắn** | `message` | Text | Có | `required|string|min:10|max:3000` | Chi tiết nội dung |
| **Mã bảo vệ Captcha** | `captcha` | String | Có | `required|captcha` | Chống spam bot qua `mews/captcha` |

## 4.5. Cơ chế Xử lý & Phản hồi (SLA & Ticket Code)

1. Khi người dùng gửi form hợp lệ:
   - Hệ thống tự sinh mã yêu cầu ngẫu nhiên định dạng `#DF-XXXXX` (Ví dụ: `#DF-88392`).
   - Ghi nhận thông tin vào cơ sở dữ liệu `contact_inquiries` với trạng thái ban đầu `pending`.
   - Lưu trữ địa chỉ IP client và User-Agent phục vụ mục đích kiểm toán an ninh.
2. Hiển thị **Success Modal**:
   - Modal chúc mừng xuất hiện trên màn hình với mã yêu cầu đã sinh.
   - Cam kết phản hồi chính thức qua email trong vòng **2 - 4 giờ làm việc hành chính**.
   - Tự động xóa trắng (reset) biểu mẫu và làm mới mã Captcha sẵn sàng cho lượt tiếp theo.

## 4.6. Thiết kế Kỹ thuật Backend

### 4.6.1. Bảng cơ sở dữ liệu `contact_inquiries`

```sql
CREATE TABLE contact_inquiries (
    id BIGSERIAL PRIMARY KEY,
    ticket_code VARCHAR(32) UNIQUE NOT NULL,
    full_name VARCHAR(100) NOT NULL,
    work_email VARCHAR(150) NOT NULL,
    phone VARCHAR(20) NOT NULL,
    company VARCHAR(150) NOT NULL,
    topic VARCHAR(50) NOT NULL,
    message TEXT NOT NULL,
    status VARCHAR(30) DEFAULT 'pending' NOT NULL,
    ip_address VARCHAR(45) NULL,
    user_agent TEXT NULL,
    created_at TIMESTAMP NULL,
    updated_at TIMESTAMP NULL
);
CREATE INDEX idx_contact_inquiries_ticket ON contact_inquiries(ticket_code);
CREATE INDEX idx_contact_inquiries_status ON contact_inquiries(status);
```

### 4.6.2. Kiến trúc Module (MVC + Service)

- **Model**: `App\Models\ContactInquiry`
- **Service**: `App\Services\Contact\ContactService` chịu trách nhiệm tạo mã ticket, gán metadata và lưu trữ inquiry.
- **Request**: `App\Http\Requests\ContactRequest` kiểm tra toàn bộ validation và rule `captcha`.
- **Controller**: `App\Http\Controllers\Public\ContactController` điều phối route `index` và `store`.
- **Đa ngôn ngữ**: Hỗ trợ đầy đủ tiếng Việt (`vi`), tiếng Anh (`en`) và tiếng Nhật (`ja`).
